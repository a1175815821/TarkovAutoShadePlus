TarkovAutoShadePlus 界面设计说明

Windows 本地 SDR 显示滤镜工具，面向《Escape from Tarkov》与《Escape from Tarkov Arena》。

v2.0.0 · WPF / .NET Framework 4.8 · 2026-09-19

这是什么

程序通过 Windows SetDeviceGammaRamp 改写显示器的 256 级 RGB Gamma 曲线， 按当前画面自动计算目标曲线并平滑应用。不读取游戏进程内存、不注入 DLL、不创建覆盖层、不模拟键鼠输入。

界面语言是「战术终端」：深色底、琥珀色强调、等宽字体标注数值与状态。 所有数字读数都使用等宽字体，便于在调整过程中对比前后差异。

动效与过渡

Gamma 曲线切换不能在两帧之间跳变，否则会看到明显的闪一下。v2.0 把过渡改成时间驱动： 

步数 = max(10, round(时长 / 基准间隔))     // 基准间隔 40ms
单步间隔 = max(16, round(时长 / 步数))      // 不低于一帧
进度 = 已耗时 / 总时长                      // Stopwatch，不依赖定时器计数
缓动 = t * t * (3 - 2t)                    // SmoothStep

过渡时长随曲线落差缩放：260 + 落差 × 900 ms。落差越大，过渡越慢，避免大幅变化时仍然突兀。

实时模式另有一层平滑：画面特征先过 EMA，时间常数在 9.0s（抑制噪声）与 0.7s（快速跟随）之间按变化幅度插值。 夜视判定走未经平滑的原始帧，保证夜视保护不被平滑拖慢。

已知限制

  • Gamma Ramp 作用于目标显示器的整个 SDR 桌面，不只作用于游戏窗口。
  • HDR、独占全屏、显卡驱动或第三方色彩管理软件可能覆盖或忽略 Gamma Ramp。
  • 截图监听只识别 .png。
  • 显示器硬件亮度与对比度仅在单屏模式下检测到 DDC/CI 支持时可用。
  • 关闭滤镜后程序仍监听截图目录，新截图会自动重新开启滤镜。
