# TarkovAutoShadePlus

Windows 本地 SDR 显示滤镜工具，面向《Escape from Tarkov》与《Escape from Tarkov Arena》的暗部可见度与高光舒适度优化。

程序通过 Windows `SetDeviceGammaRamp` 改写显示器的 256 级 RGB Gamma 曲线，按当前画面自动计算目标曲线，并以平滑过渡的方式应用。**不读取游戏进程内存、不注入 DLL、不创建游戏覆盖层、不模拟键鼠输入。**

- 版本：**v2.2.0**
- 运行环境：Windows 10 / 11，.NET Framework 4.8（缺少 4.8 开发包时回退 4.7.1）
- 产物：`bin-wpf/TarkovAutoShadePlus.exe`

## 三种工作方式

三种方式可以任意组合，最终都走同一条「分析 → 计算曲线 → 平滑应用」的链路。

### 1. 截图监听（默认开启）

监听游戏截图目录，新截图写入完成后自动分析并应用曲线。

```text
游戏生成截图 -> 监听目录并等待写入完成 -> 缩放提取亮度/颜色/动态范围特征
             -> 结合当前生效的参数档案计算推荐曲线 -> 生成 256 级 RGB Gamma Ramp
             -> 平滑应用到目标显示器
```

默认目录（启动时自动查找，找不到会在界面提示手动选择）：

```text
文档\Escape from Tarkov\Screenshots
文档\Escape from Tarkov Arena\Screenshots
```

> 只识别 `.png`。用第三方工具输出 jpg/bmp 不会触发。

### 2. 实时全自动（v2.0 新增，默认关闭）

不需要截图，按固定间隔抓取画面分析。可在「实时全自动」面板开启。

- **采样间隔**：600 ~ 3000 ms，默认 800 ms。
- **跟随灵敏度**：保守 / 均衡 / 灵敏。保守换得慢但最稳，灵敏跟得快但更容易被枪火与闪光带偏。
- **自适应平滑**：画面特征先过一道 EMA（时间常数在 9.0s 噪声抑制与 0.7s 快速跟随之间按变化幅度插值），消除单帧抖动带来的呼吸感。
- **夜视切换优先**：夜视判定走未经平滑的原始帧，平滑不会拖慢夜视保护的介入。
- **限制**：仅 SDR + 无边框/窗口化有效；独占全屏与 HDR 下 Gamma 会被系统忽略。

### 3. 手动分析

点「立即分析」对最近一张截图重算一遍。拖动滑块也会实时重算预览并套用。

## 参数档案：原版 / 竞技场独立调参

两个游戏端的画面对比度基线不同，共用一套参数必然有一端偏过。v2.0 把参数拆成两份档案：

- **原版**：`EscapeFromTarkov.exe` / `Escape from Tarkov\Screenshots`
- **竞技场**：`EscapeFromTarkovArena.exe` / `Escape from Tarkov Arena\Screenshots`

界面上的「参数档案」面板：

- `原版` / `竞技场` 两个按钮：点哪个就编辑哪个档案，下方所有滑块随之切换。
- `跟随前台游戏自动切换`：开启后按当前前台窗口或截图来源自动取用对应档案；关闭则锁定在当前选中的档案。
- 面板底部显示「当前生效：原版 / 竞技场」。

竞技场档案在复制原版参数的基础上，亮度微调额外 `-3`。

> 实现上，界面里的平铺字段始终镜像「当前生效的那一份档案」，未生效的另一份只作为存储。因此你切换档案时看到的就是该端真实的参数，不会出现两边互相污染。

## 工作原算法原理

界面上的滑块是**固定的算法偏好**，不是固定的最终亮度。同一组参数在不同截图上会算出不同的曲线：

```text
LUT = ToneCurve(图像特征, 当前生效的参数档案)
```

- `图像特征`：本次画面算出的亮度分位数、颜色均值、动态范围、边缘能量、夜视特征等。
- `参数档案`：暗部可见度、高光保护、最大调整强度等偏好，以及强度上限。
- `LUT`：本次实际写入的 256 级 RGB Gamma 曲线。

像素内容与参数完全相同时，结果必然相同；算法不会随机改变滤镜。

### 画面分析的主要数据

截图会先缩放到约 `320 x 180` 再分析主体区域，降低 HUD、窗口边缘和武器模型的干扰：

- `P10`：偏暗区域亮度，判断暗部缺失程度。
- `Median / P50`：画面典型亮度，判断明暗场景。
- `P75 / P95`：中高亮与高光，保护天空、灯光、窗户。
- `DynamicRange`：亮暗跨度，判断画面是否发灰或对比过强。
- `BrightFraction`：高亮像素比例，辅助判断室外与强光。
- `MeanRed / MeanGreen / MeanBlue`：通道均值，用于色偏校正与色彩浓度。
- `NightVisionScore`：偏绿且偏暗的夜视特征，用于夜视保护。

## 参数说明

### 自动算法偏好

控制算法面对不同环境时的倾向，不会在分析后自动变成另一组数值。

| 参数 | 默认 | 作用 |
| --- | ---: | --- |
| 暗部可见度 | `70` | 提高暗场增强倾向。越高，暗场允许的提亮幅度越大。 |
| 高光保护 | `76` | 保护天空、窗户、灯光与高亮区域。越高，检测到高光时越抑制提亮。 |
| 色偏校正 | `72` | 按 RGB 均值做轻量通道平衡，减少整体偏色。 |
| 室内柔和 | `72` | 检测到室内特征时降低中间调冲击、增加柔和压缩。 |
| 过亮 / 夜视保护 | `88` | 保护强光、逆光与偏绿夜视场景，避免自动增强过度。 |
| 黑位 / 去灰 | `56` | 提亮暗部后恢复黑色分离度，减少灰雾感。过高会损失暗部细节。 |
| 最大调整强度 | `82` | 生成曲线与原始曲线的最大混合比例。**不是亮度值，也不是 Gamma 值。** |

### 画面微调

在自动分析结果之上的固定偏移，`0` 表示不调整。

| 参数 | 默认 | 作用 |
| --- | ---: | --- |
| 亮度微调 | `0` | 整体曝光倾向。高光保护会限制它在强光场景中的作用。 |
| 对比度微调 | `0` | 增加或减少明暗分离。 |
| 暖色舒适度 | `0` | 正值偏暖，负值偏冷。 |
| 色彩浓度 | `0` | 调整颜色通道相对画面亮度的距离。 |

### 快捷预设

预设只是不同的参数组合，选择后仍会按每张画面重算曲线：

`自动分析` · `自然中性` · `室内柔和` · `夜视护眼` · `高光保护` · `自定义预设`

拖动任意滑块会把预设切到「自定义预设」，并把当前数值存入自定义档。

「色彩聚焦」是独立的叠加层：切换前五个内置预设不会重置它，选择「自定义预设」时才会连同它一起保存与恢复。

## 色彩聚焦（定向调色）

右栏底部的独立面板。它把**一个选定色相**的通道在指定亮度区间里推高，同时把其余通道按比例压回，
观感上就是目标色系变浓、互补色变淡，别的颜色被弱化一点。

| 参数 | 默认 | 作用 |
| --- | ---: | --- |
| 目标色调 | `25°` | 要增强的色相。彩虹条给出整圈色相，右侧色卡显示当前选中的颜色。下面四个按钮是常用目标：火光橙 `25°`、血迹红 `0°`、植被绿 `110°`、霓虹青 `195°`。 |
| 聚焦强度 | `0` | 双向强度。增大时目标色相的通道被推高、其余通道被压回；`0` 表示完全不参与计算。 |
| 作用亮度 | `0` | 聚焦作用在画面的哪一段亮度。负值偏暗部（角落、暗室），正值偏亮部（灯光、天空），`0` 为中间调。 |
| 手动调色 红 / 绿 / 蓝 | `0` | 分通道直接偏移，与目标色调叠加，用于自己校色。 |

满强度下中间调的偏移量约 ±30 / 255，实际常用区间是 15 ~ 45。
点四个快捷色相按钮时，若聚焦强度还是 0，程序会把它置为 `35` 并在顶栏提示——否则点了没有任何变化，容易被当成功能失效。

### 它能做到什么，做不到什么

`SetDeviceGammaRamp` 只允许按「通道 × 输入电平」改写 256 级曲线，程序拿不到一个像素的另外两个通道，
因此**做不到真正的 HSV 选区**——不存在「只把橙色物体提亮、别的一概不动」。

实际实现是**通道偏向式定向调色**，以 25° 暖橙为例：

```text
目标色相 25° -> 通道权重 R 1.00 / G 0.42 / B 0.00
推高：R + 0.085×强度   G + 0.036×强度   B + 0.000×强度
压回：R - 0.000×强度   G - 0.043×强度   B - 0.075×强度
```

两点需要知道：

- **中性画面也会被染色**。曲线只认亮度不认色相，灰色墙面、白色护甲同样会朝目标色偏。
  想要更克制就把聚焦强度放低。
- **黑场与白场不受影响**。作用亮度的窗口在纯黑与纯白处恒为 0，所以不会污染端点，也不会在最高一级撞出台阶。

目标是「暗处更看得见、其余颜色退后一点」的话，把目标色调选在敌人的色调上，
聚焦强度设到 20 ~ 35，作用亮度略微偏向暗部即可。

聚焦会一并写进发给 OBS 的 LUT，联动侧不需要额外设置。

### 启用开关

面板标题右侧的「启用」缺省勾选。取消勾选后**下面所有数值都保留、但完全不参与计算**，
同时控件置灰——方便你在「有 / 无」之间来回对比，不用把调好的参数清掉。
关闭状态下生成的曲线与不加色彩聚焦时逐像素一致。

## 臂环增强（红 / 蓝双色）

右栏最底部，默认**关闭**。目标是让红 / 蓝臂环更早被认出来。

| 参数 | 默认 | 作用 |
| --- | ---: | --- |
| 双色强化 | `0` | 抬升红、蓝通道的饱区（权重 `v²`，中性灰所在的中间调权重只有 0.25）。红蓝更亮更艳。 |
| 环境去色 | `0` | 压制绿通道的中间调，让橄榄、灌木、草地退色。 |

满强度实测（对真实截图整帧求均值，基线 R51.0 / G53.6 / B53.8）：

| 设置 | 结果 |
| --- | --- |
| 双色强化 100 | R 52.4、G 53.6（**完全不变**）、B 55.5 |
| 环境去色 60 | R 51.0（**完全不变**）、G 45.9、B 53.8（**完全不变**） |

### ⚠️ 「其余颜色变黑白、只留红蓝」做不到

这是**数学上做不到**，不是参数没调好。

程序写出的是一组 Gamma Ramp，也就是三条**互相独立**的曲线 `R(i) / G(g) / B(b)`。
R 曲线在决定第 137 档输出多少时，只看得到这个像素的红通道值，看不到它的绿和蓝。
而「把这个像素变成灰」必须比较三个通道的相对关系——比如先判断「G 是不是三者里最大的」。
曲线做不到这件事，所以不存在真正的 HSV 选区。

唯一能逼近的方向是把绿通道压掉（也就是「环境去色」）。它确实能让绿 / 橄榄 / 草木退色，
但同样是通道级操作，代价必须明说：

- **中性灰与混凝土会偏品红。** 满强度下 128 档的绿被压掉 22 / 255，这部分偏色在数学上
  无法和「选择性去色」拆开，只能靠强度换。实测 60 强度时整帧已经从灰色偏向粉紫。
- **褐色木料、土黄沙地反而会更艳**（实测饱和度 +36% / +14%），会和**红**臂环抢注意力。
- **冷光与天空会明显更蓝**（实测 +68%），会和**蓝**臂环抢注意力。

所以这一项目的是「把红蓝从环境里拉出来」，不是「让其他颜色消失」。
建议环境去色不超过 40；要更克制的对比，用「双色强化」就够了。

## 使用方法

1. 运行 `TarkovAutoShadePlus.exe`。
2. 在「显示器模式」选「单屏模式」或「多屏模式」；多屏模式下至少勾选一个显示器。
3. 接入或移除显示器后，点「刷新显示器」同步列表。
4. 确认截图目录。默认目录找不到时点「选择目录」。
5. 确认「自动监听新截图并应用」已开启；需要免截图跟随就再开「实时全自动」。
6. 进入新的室内 / 室外 / 夜视 / 逆光环境后生成一张截图，等待分析完成即可看到曲线平滑应用。
7. 用全局快捷键切换滤镜，默认 `F8`，可在设置中修改。

关闭滤镜后程序仍继续监听截图目录；检测到新截图会自动分析并重新开启滤镜。

界面底部显示的「等效 Gamma」「亮度调整」「对比度调整」是**最近一次画面算出的实际结果**，不是滑块本身的值。等效 Gamma 只是便于理解的显示指标，程序内部用它的倒数生成曲线，因此等效 Gamma 变大通常意味着暗部提升倾向变强，不等于画面变暗。

## 显示器硬件（DDC/CI）

单屏模式下会探测显示器的 DDC/CI 能力；支持时可在界面直接调整硬件亮度与对比度，不支持时界面如实显示不可用，不会伪装成可用功能。多屏模式下请分别在显示器 OSD 里调整。

---

## 显示范围与限制

- Gamma Ramp 作用于目标显示器的**整个 SDR 桌面**，不只作用于游戏窗口；多屏模式下只作用于已勾选的显示器。
- HDR、独占全屏、显卡驱动或第三方色彩管理软件可能覆盖或忽略 Gamma Ramp。
- 不会提升纹理分辨率，也不替代游戏内抗锯齿、锐化或显示器硬件亮度设置。
- 平滑过渡只改变曲线**应用过程**，不改变自动分析的最终目标曲线。
- 截图监听只识别 `.png`。
- 主窗口最小尺寸 1060 × 700；已声明 PerMonitorV2 DPI 感知。

## 本地运行与隐私

程序只在本机完成以下工作：

- 读取本机截图文件并分析像素。
- 用 Windows `SetDeviceGammaRamp` 应用 Gamma 曲线。
- 在 `%LOCALAPPDATA%\TarkovAutoShade` 保存设置、异常退出恢复数据与 OBS 联动状态文件。
- 可选读取显示器 DDC/CI 信息。
